Features / AI assistant, CEC helper and MCP

AI assistant

AI drafts it. You approve it.

Tell the assistant about the job in your own words, add a photo, and it drafts the estimate from your price book. Nothing is sent, invoiced or deleted until you press the button.

Included in: Business and up Compare plans

Start free trial See pricing

What it does

  • Drafts from your notesEstimates and invoices from a description or a photo, priced from your price book, as drafts for you to check.
  • CEC helperCode questions answered with the same calculators the app uses, with the rule references, for your province and code book.
  • Background checksDaily checks that draft suggestions: a quote with no follow-up, an invoice overdue. They draft; you send.
  • MCP serverConnect Claude Desktop, Claude Code or another MCP client to your company's data with a scoped API key you can revoke.

How it works on site

  1. Connect your own Anthropic account in Integrations (we can set it up for you).
  2. Open "Ask Fishtape" on an estimate, an invoice or a job.
  3. Describe the work or add a photo. The assistant drafts and shows its working.
  4. Review the draft, change what you like and approve it.

Which plan includes it

Every plan has no caps on invoices, estimates, jobs, clients or drawings. Plans differ by features and included users.

  • AI assistantBusiness and up
  • AI code helperBusiness and up
  • Background AI agentsBusiness and up
  • MCP server for AI toolsBusiness and up
  • API accessBusiness and up

Good to know. The AI runs on your company's own Anthropic API key, so you see and control what it costs, with a monthly cap. Conversations are private to the person who started them and deleted after 180 days without activity. The CEC helper is an aid, not a replacement for the code book or the inspector.
