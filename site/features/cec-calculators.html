CEC calculators

The code book maths, with the rule beside every answer

Size the conductor, check the voltage drop, fill the conduit and the box, and work out the service. Each answer cites the CEC rule or table so you can check it.

What it does

  • Conductors and voltage dropTables 1 to 4 ampacity at 60, 75 and 90 °C, copper and aluminium, terminations (4-006), continuous loads (8-104) and 8-102 voltage drop.
  • Conduit and box fillRule 12-910 with Tables 6, 8 and 9 for EMT, rigid, PVC, ENT and flex; Rule 12-3034 with Tables 22 and 23 for boxes.
  • Demand loads8-200 single dwellings, 8-202 apartments and 62-118 electric heat, with Ontario's Table 39.
  • Motors and bondingTables 44, 45 and 29, Rules 28-106, 28-200 and 28-306, and Table 16 bonding conductors.

How it works on site

  1. Pick the calculator. Your province and code book come from Settings.
  2. Enter the load, the length and the system: 120/240 V, 120/208 V, 347/600 V or 600 V.
  3. Read the answer with its rule and table references.
  4. Save it to the job, or use it in a panel schedule.

Which plan includes it

Every plan has no caps on invoices, estimates, jobs, clients or drawings. Plans differ by features and included users.

  • CEC calculatorsEvery plan
  • Panel schedulesPro and up
  • Permits and inspectionsPro and up

Good to know. CEC 2024 is the default; NEC 2023 is there for a job that needs it. The calculators cite numbers and rule references only, never CSA's text. Values we could not confirm against the printed 2024 code book are marked to verify. They are estimating aids: the inspector's reading of the code in force decides.
