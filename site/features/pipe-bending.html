Pipe bending

Every mark for every bend, drawn to scale

Pick the bend, type what you measured, and get the marks to put on the pipe with a diagram of the finished piece. Save it against the job for the next run.

Included in: Every plan Compare plans

Start free trial See pricing

What it does

  • Every common bendOffsets, kicks, 3- and 4-point saddles, 90s and stubs, back-to-backs, box offsets, rolling and parallel offsets, segment bends.
  • Your benderBuilt-in values for common hand benders, or a profile for your own with take-up and gain you measured.
  • Chart numbers or exactExact trigonometry by default. Tick Chart numbers to get the same rounded figures printed on the bender.
  • Reads how you write itType 12' 3 5/8", 30 1/2 or 450 mm. Each box shows how it read the number in both systems, so a misread gets caught before you bend.

How it works on site

  1. Pick the bend and the conduit: EMT, rigid, IMC, PVC or aluminium, trade size 16 to 103.
  2. Type the measurements from the job.
  3. Read the marks off the list, measured from the end of the pipe, with shrink and developed length.
  4. Save it to the job. It works offline in the basement.

Which plan includes it

Every plan has no caps on invoices, estimates, jobs, clients or drawings. Plans differ by features and included users.

  • Pipe bendingEvery plan
  • CEC calculatorsEvery plan

Good to know. Bend radii follow CEC Table 7. A few bender values are still marked to verify with the maker's charts; the screen shows which.
