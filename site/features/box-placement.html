Box placement and code checks

Place the boxes, then check them against the CEC

Draw a room, mark the doors and windows, and Fishtape proposes receptacles, switches, lights and alarms. Then it checks the layout and flags what an inspector would.

Included in: Pro and up Compare plans

Start free trial See pricing

What it does

  • Auto-place by room typeBedrooms, kitchens, bathrooms, hallways, laundry, garages, basements and outdoor walls each get the boxes their rules call for.
  • Kitchen counters done rightCounter receptacles at 900 mm reach, none behind the sink, GFCI near the sink, island and peninsula receptacles when they qualify.
  • Code check on the drawingNumbered markers and a list of findings with the CEC rule for each: 26-722 spacing, 26-704 GFCI, 26-658 AFCI, 26-706 tamper-resistant and more.
  • One-tap fixesSome findings fix themselves: Make GFCI, Mark AFCI, Mark TR, Mark WP cover. Turn on Live to re-check after every change.

How it works on site

  1. Set the scale, then draw the room with the Room tool (rectangle or polygon) and pick its type.
  2. Add doors, windows, the range, the island. Hinge side and swing count for usable wall.
  3. Tap Auto-place. Proposals show as dashed ghosts with the reason and rule. Accept, nudge or discard.
  4. Tap the shield to run the code check. Fix what it flags and the takeoff follows.

Which plan includes it

Every plan has no caps on invoices, estimates, jobs, clients or drawings. Plans differ by features and included users.

Good to know. The checks follow CSA C22.1:24 with provincial amendments. A few rule numbers are still marked to verify against the printed 2024 code book, and smoke and CO alarm rules come from the building code. It is a layout and estimating aid: the inspector's reading of the code in force decides.
